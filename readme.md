A Dogecoin tipping page, a streamer utility and a community guest book, running
entirely as a static site. No server, no database, no monthly bill - which was
the point, and the reason it still works years after anyone stopped touching it.

**Archived.** Live at [dogefundme.com](https://dogefundme.com) because Pages
keeps serving an archived repository.
